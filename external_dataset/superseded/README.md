# Superseded patient-cohort scripts

The scripts in `external_dataset/superseded/` are an earlier exploratory version of the GSE176031 analysis.
They use an unweighted module score over 25 of the 26 signature genes and fit a mixed-effects model for one
proliferation measure only. They do not reproduce Supplementary Table S1 or Supplementary Figure S8 and are
retained only for provenance.

The analysis reported in the manuscript uses the fold-change-weighted, signed score over all 26 genes,
described in the Supplementary Material.
